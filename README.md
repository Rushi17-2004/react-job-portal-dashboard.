# React Job Board Dashboard (Vanilla CSS)

A clean, modern job listing interface built with React.js and styled entirely with custom, pure Vanilla CSS.

## 🚀 Technical Highlights
- **Pure Vanilla CSS:** Built completely from scratch without utility frameworks, proving strong fundamentals in standard CSS structure.
- **Flexbox Architecture:** Utilizes clean, responsive Flexbox layout logic to align dynamic components flawlessly across the viewport.
- **Dynamic Component Mapping:** Leverages JavaScript array methods (`.map()`) to dynamically feed real-world job details as props into a clean, reusable `Card` component.

## 🛠️ Tech Stack
- **Frontend Framework:** React.js (Vite)
- **Styling:** Vanilla CSS3
- **Language:** JavaScript (ES6+), HTML5
